# Repository layer

Слой работы с данными выделен отдельно, чтобы сервисы не зависели от конкретной
СУБД или ORM. В лабораторной №3 health-check проверяет только доступность процесса,
поэтому соединение с базой данных ещё не создаётся. Репозитории предметных сущностей
подключаются на следующих этапах разработки через интерфейсы этого слоя.
